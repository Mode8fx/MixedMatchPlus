# Mixed Match Plus

_Mixed Match Plus_ is a hack of Tetris & Dr. Mario that makes several improvements to Mixed Match:

- Added a proper single player mode, complete with results screen! No more letting the second player Game Over repeatedly.
- Added an onscreen timer! No more guessing how much time is left. It also has a different design for both Tetris and Dr. Mario, with each half reflecting that player's game in multiplayer.
- Renamed the "OPTION" menu setting to the more accurate "CUSTOM GAME".
- Added a music setting to the Custom Game menu. The player originally had to choose a song in the standard game menu, then backtrack to Option/Custom Game.
- Reorganized both menus to accomodate the new settings.

The download can be found [here](https://github.com/Mode8fx/MixedMatchPlus/tree/main/patches).

## Notes
- AI was used in the development of this hack (specifically, GPT 6.1 Sol), with human playtesting by me. Everything works as far as I can tell, but feel free to submit an issue if you find any bugs and I will fix them.
